# 일확천금 · LOTTO LAB

로또 6/45 전 회차(1회~최신)를 통계로 분해하고, 조합을 만들고, 등수를 시뮬레이션하고,
실제 구매 기록까지 관리하는 **단일 HTML 도구**.

> **웹에서 바로 열기** → `https://<사용자명>.github.io/<저장소명>/`
> (저장소를 처음 올린 뒤 Settings → Pages → Source 를 **GitHub Actions** 로 바꾸면 활성화됩니다)

서버도, 빌드도, 데이터베이스도 없습니다. `index.html` 하나가 브라우저에서
동행복권 공식 API를 직접 호출해 전 회차를 받아오고, 결과를 브라우저에 캐시합니다.

## 이 도구가 실제로 찾아낸 것

전 회차를 다 뒤진 결과, 번호 선택으로 바꿀 수 있는 건 **딱 하나**였습니다.

| 통념 | 검정 결과 |
|---|---|
| 잘 나오는 번호가 있다 | ❌ 카이제곱 균일성 검정 통과 |
| 오래 안 나온 번호는 나올 때가 됐다 | ❌ 기하분포 그대로 (도박사의 오류) |
| 동반쌍에 패턴이 있다 | ❌ 이항분포 범위 안 |
| 추첨 순서에 신호가 있다 | ❌ 순번별 카이제곱 전부 잡음 |
| **당첨자 수는 줄일 수 있다** | ✅ **t값 4 이상으로 실증** |

1·2·3등 당첨금은 **고정 풀을 당첨자 수로 나눕니다.** 확률(분자)은 못 바꿔도 **분모는 바꿀 수 있습니다.**

그 회차 당첨번호가 얼마나 인기 있었는지는 **4등·5등 당첨자 수가 기대치보다 얼마나 많았나**로 직접 측정됩니다.
(기대 4등 = 총판매게임수 × 11,115 / 8,145,060)
4등 기준 지수와 5등 기준 지수의 **상관이 0.92** — 서로 독립인 두 측정이 일치하므로 실재하는 현상입니다.

이 지수를 조합 구조에 회귀한 결과, 유의한 특징이 나왔습니다:

- **12 이하 번호 개수** — 많을수록 당첨자 증가 (t ≈ 4.1)
- **번호 범위(최대−최소)** — 넓을수록 당첨자 감소 (t ≈ −4.0)
- **끝수 중복** — 있을수록 당첨자 증가 (t ≈ 2.5)

「조합 생성」 탭의 **「최소 분배 ★」** 전략이 이 모델을 씁니다.
확률은 그대로 1/8,145,060 이지만, 당첨 시 **기대 수령액**이 대략 10~15% 올라갑니다.

## 데이터 출처

**당첨번호 · 1~5등 당첨자수 · 1게임당 당첨금 · 총판매액 · 1등 자동/수동/반자동 구성비**
동행복권 공식 엔드포인트 `/lt645/selectPstLt645InfoNew.do`
(2026년 사이트 개편으로 예전 `common.do?method=getLottoNumber` 는 폐기됨)

**추첨순서(공 나온 순서)** — 공식 데이터에 **없습니다.**
공식 API의 `tm1~tm6WnNo` 는 순서처럼 보이지만 전부 오름차순 정렬값입니다.
이 도구의 순서 데이터는 방송 기록 아카이브 수집분이며, 전 회차에 대해
**6개 번호 집합과 보너스가 공식 데이터와 100% 일치함을 검증**했습니다.

| 구간 | 상태 |
|---|---|
| 1~396회, 468~1238회 | 검증됨 (아래 개별 회차 제외) |
| **397~467회** | **신뢰 불가** — 71회 연속 전부 오름차순 = 실제 순서가 아닌 자리표시자 |
| 626·635·637·642·643·645·652·655·664·666~670·756·824 | 판정 보류 — 오름차순이라 구분 불가 |

## 데이터가 끊기지 않는 3중 안전망

1. **브라우저 자체 수집** — 페이지를 열 때마다 최신 회차만 증분으로 받아 캐시 *(기본)*
2. **주간 자동 갱신** — 일요일 09:00 KST, `lotto-history.json` 스냅샷 갱신
   (`.github/workflows/update-data.yml` + Cowork 예약 작업)
3. **`데이터-갱신.bat`** — PC에서 수동 전량 재수집

세 경로 중 하나만 살아 있으면 데이터는 유지됩니다.

## 경고

**이 도구는 예측하지 않습니다.**

- 각 회차는 독립 시행입니다. 지난 1,238회는 다음 회차에 아무 정보도 주지 않습니다.
- 어떤 6개를 고르든 1등 확률은 **1/8,145,060** 으로 동일합니다.
- 로또의 구조적 기대 회수율은 판매액의 **약 50%** 입니다. 장기적으로 구매액의 절반은 반드시 사라집니다.

바꿀 수 있는 건 "만약 터졌을 때 얼마를 받느냐" 하나뿐이고, 그것도 ±10~15% 입니다.
