# 예약 작업 프롬프트

예약 작업이 «이 컴퓨터에 바인딩» 되어 있어, **프롬프트 변경은 데스크톱에서 승인해야** 적용된다.
이름·주기·켜기끄기는 승인 없이 바뀐다.

| 파일 | 작업 | 주기 |
|---|---|---|
| `friday-pension.md` | 연금 채점 + 구매 직전 재생성 + 검증 보드 | 금 08:00 (cron `0 23 * * 4` UTC) |
| `sunday-lotto.md` | 로또 채점 + 데이터 갱신 + 검증 보드 | 일 09:00 (cron `0 0 * * 0` UTC) |

## 적용 방법

데스크톱 앱에서 해당 예약 작업을 열고 프롬프트를 위 파일 내용으로 통째로 교체한다.
**삭제 후 재생성하지 말 것** — 실행 이력과 컴퓨터 연결이 날아간다.

## 2026-09-06 개편에서 바뀐 것

1. `scripts/validate.mjs` 실행 추가 — 검증 보드와 실구매 원장을 매번 갱신
2. `--purchases` 로 기존 `brief/purchases.json` 을 넘김 (**빠뜨리면 원장이 매주 초기화된다**)
3. 커밋 대상에 `validate.html`, `brief/purchases.json`, `brief/validation.json` 추가
4. 보고 항목에 «실구매 원장 누적» 과 «검증 보드 요약» 추가
5. 주간 구매 규모 명시 — 로또 5줄 + 연금 5장 = 10,000원
6. 「한 주 실적으로 규칙을 판단하지 마라」와 **보정 p** 를 원칙에 추가
